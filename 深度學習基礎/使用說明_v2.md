## 開始使用

1. 若使用 ZIP，先完整解壓縮，保留 Notebook、data 與 outputs 的相對位置。
2. 使用 VS Code 開啟教材資料夾，選擇安裝 PyTorch、NumPy、Pandas、scikit-learn、Matplotlib、IPython 的 Python Kernel。從零安裝的指令在教材第 7 節。
3. 選擇 Restart Kernel → Run All。Notebook 已保留一次實際執行的輸出，你可以重新跑出自己的結果。
4. 若修改參數，從頭執行以重建模型、Optimizer 與資料切分。只重跑訓練格會從目前權重繼續訓練。
5. 圖表與表格會寫入 outputs/v2。同名輸出會被新的執行取代。

## 本次實際驗證

2026-10-25 在現有專案環境，以 PyTorch 2.11.0+cu128、CUDA 執行全部 26 個程式儲存格，沒有錯誤或 stderr 警告；另外完成 CPU 載入權重後的新顧客推論，與原預測在容許浮點誤差內一致。未另外執行整套 CPU 訓練。

資料切分為 Train 1,800／Validation 600／Test 600。驗證集選出的最佳模型為第 12 輪，Test Accuracy=0.7600、F1=0.7692、ROC AUC=0.8546；Logistic Regression 的 ROC AUC=0.8552。這些只是本次合成資料、設定與環境下的結果，不是學生必須達成的固定答案。

## 放到 Notion

先以 Markdown 副本搬移文字、表格與程式碼，再從 outputs/v2 上傳自己的圖表與預測結果。Markdown 副本不會自動同步 Notebook 後續輸出。概念圖只提供提示詞，待你之後自行生成並上傳；本次沒有產生概念圖片或建立 Notion 頁面。
